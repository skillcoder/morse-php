# PHP 7.1 → 7.2

Read this file when the migration range includes PHP 7.2.

## Official sources
- https://www.php.net/manual/en/migration72.incompatible.php
- https://www.php.net/manual/en/migration72.deprecated.php
- https://www.php.net/manual/en/migration72.other-changes.php
- https://github.com/php/php-src/blob/PHP-7.2/UPGRADING

## Breaking
- `count()` / `sizeof()` on a non-countable value (`null`, scalar, plain object) emits `E_WARNING` (becomes `TypeError` in 8.0).
- Undefined constants (bare words) emit `E_WARNING` (become `Error` in 8.0).
- `get_class(null)` warns instead of returning the enclosing class name.
- `object` is a reserved class/interface/trait name.
- `number_format()` never returns `"-0"`.
- Array ↔ object casts convert numeric keys, so `(object)['0' => 1]` is readable as `->{'0'}`.
- `array_unique()` with `SORT_STRING` may give a different next auto-index.
- `json_decode()` honours `JSON_OBJECT_AS_ARRAY` when `$assoc` is `null`.
- `rand()`/`mt_rand()` ranges give different sequences on 64-bit (modulo bias fix).
- `bcmod()` no longer truncates fractional operands.
- `gettype()` on a closed resource returns `"resource (closed)"`; `is_object()` is true for `__PHP_Incomplete_Class`.
- `ext/hash` contexts are objects; `hash_hmac()` and friends reject non-cryptographic algorithms.
- `ext/mcrypt` removed from core (PECL).

## Deprecated (removed in 8.0)
- `__autoload()` → `spl_autoload_register()`.
- `create_function()` → closures.
- `each()` → `foreach`.
- `(unset)` cast.
- `parse_str()` without the result argument.
- `assert()` with a string argument.
- `$php_errormsg` / `track_errors` → `error_get_last()`.
- `mbstring.func_overload`, the `$errcontext` error-handler argument, `gmp_random()`, `png2wbmp()`, `jpeg2wbmp()`, `INTL_IDNA_VARIANT_2003`, `read_exif_data()`.

## Rector covers
Rector 2.7.0 set `php72`: `CreateFunctionToAnonymousFunctionRector`, `WhileEachToForeachRector`, `ListEachRector`, `ReplaceEachAssignmentWithKeyCurrentRector`, `ParseStrWithResultArgumentRector`, `StringsAssertNakedRector`, `StringifyDefineRector`, `GetClassOnNullRector`, `UnsetCastRector`, `RenameFunctionRector` (removed aliases).
Not covered: `__autoload()` → `spl_autoload_register()`, `count()` on non-countables, bare-word constants, `$php_errormsg`.

## Tools miss — review manually
- `count()` on values that can be `null` or scalar at runtime (only tests or PHPStan show these).
- Bare-word constants used as strings.
- Tests that assert seeded random output or `-0` from `number_format()`.

## Grep patterns
Regexes are ripgrep syntax (usable with the Grep tool). Review every hit; a hit is a place to look, not proof of a bug.

- `\beach\(` — removed in 8.0
- `\bcreate_function\(` — removed in 8.0
- `function\s+__autoload\b` — removed in 8.0
- `\(unset\)` — removed cast
- `parse_str\([^,]*\)` — missing result argument
- `\bassert\(\s*['"]` — string assertion
- `\$php_errormsg` — removed variable
- `\b(count|sizeof)\(` — argument may be non-countable
- `get_class\(\s*\$` — may receive `null`
