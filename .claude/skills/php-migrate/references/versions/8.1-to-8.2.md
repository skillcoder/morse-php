# PHP 8.1 → 8.2

Read this file when the migration range includes PHP 8.2.

## Official sources
- https://www.php.net/manual/en/migration82.incompatible.php
- https://www.php.net/manual/en/migration82.deprecated.php
- https://www.php.net/manual/en/migration82.other-changes.php
- https://github.com/php/php-src/blob/PHP-8.2/UPGRADING

## Breaking
- `str_split("")` returns `[]` (was `[""]`).
- `strtolower()`, `strtoupper()`, `lcfirst()`, `ucfirst()`, `ucwords()`, `stristr()`, `stripos()`, `strripos()`, `str_ireplace()`, `array_change_key_case()` and `SORT_FLAG_CASE` are ASCII-only and locale-independent.
- `strcmp()`, `strcasecmp()`, `strncmp()`, `strncasecmp()`, `substr_compare()` may return `-1`/`1` instead of the length difference.
- `ksort()`/`krsort()` with `SORT_REGULAR` use PHP 8 numeric-string rules.
- `var_export()` prints class names with a leading backslash.
- `iterable` is an alias of `array|Traversable` (error messages change).
- `random_int()`/`random_bytes()` throw `Random\RandomException`.
- `glob()` returns `[]` when `open_basedir` blocks every path; `FilesystemIterator` no longer forces `SKIP_DOTS`.
- Default timezone falls back to UTC when `date.timezone` is unset.

## Deprecated
- **Dynamic properties**: assigning an undeclared property on a class without `__get`/`__set` (`stdClass` is exempt). Declare the property; `#[\AllowDynamicProperties]` is a last resort.
- `"${var}"` and `"${expr}"` interpolation → `"{$var}"` / `"{${expr}}"`.
- Partially supported callables: `"self::m"`, `"parent::m"`, `"static::m"`, `["self", "m"]`, `["parent", "m"]`, `["static", "m"]`, `["Foo", "Bar::m"]` → `[self::class, 'm']` or `self::m(...)`.
- `utf8_encode()`/`utf8_decode()` → `mb_convert_encoding()`.
- mbstring `QPrint`, `Base64`, `Uuencode`, `HTML-ENTITIES` encodings.

## Rector covers
Rector 2.7.0 set `php82`: `VariableInStringInterpolationFixerRector` (`${var}` → `{$var}`), `Utf8DecodeEncodeToMbConvertEncodingRector`, `FilesystemIteratorSkipDotsRector`.
- **Skipped by default (risky):** `ReadOnlyClassRector`.
Not covered — **fix by hand**: dynamic properties (declare them), relative callables (`"self::m"`), `str_split("")`.

## Tools miss — review manually
- Properties set dynamically through variables (`$this->$name = …`) or from outside the class.
- Loops over `str_split($input)` where the input can be empty.
- Callers that use the magnitude of `strcmp()` results.
- Tests comparing `var_export()` output.

## Grep patterns
Regexes are ripgrep syntax (usable with the Grep tool). Review every hit; a hit is a place to look, not proof of a bug.

- `\$this->[a-zA-Z_]+\s*=` — property declared?
- `->\$[a-zA-Z_]+\s*=` — dynamic property by name
- `"[^"]*\$\{` — `${}` interpolation
- `['"](self|parent|static)::` — relative callable string
- `\[\s*['"](self|parent|static)['"]` — relative callable array
- `\butf8_(en|de)code\(` — deprecated
- `\bstr_split\(` — empty input
- `\bvar_export\(` — output changed
