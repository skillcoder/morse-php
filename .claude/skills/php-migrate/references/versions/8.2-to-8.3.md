# PHP 8.2 → 8.3

Read this file when the migration range includes PHP 8.3.

- https://www.php.net/manual/en/migration83.incompatible.php

## Breaking
- `range()`: objects/resources/arrays as bounds throw `TypeError`; step `0`, a negative step on an increasing range, or `INF`/`NAN` throw `ValueError`; a digit string bound gives a character range (`range('9', 'A')`); warnings for empty-string or multi-byte non-numeric bounds.
- `number_format()` with negative `$decimals` rounds left of the decimal point.
- `file()` rejects invalid flags.
- An array whose first key is negative `-n` continues at `-n+1`.
- A class using a trait with static properties gets its own copy.
- Interface constant visibility variance is checked.
- Deep recursion may throw `Error` (`zend.max_allowed_stack_size`).
- Date extension throws `DateError`/`DateException` subclasses.
- `unserialize()` notices became warnings; trailing bytes warn.
- `array_sum()`/`array_product()` warn on values that can't be converted.
- `strtok()` without a token to start warns.
- `str_getcsv()`/`fgetcsv()` unterminated final enclosure gives `""`.
- `mt_srand(null)` seeds randomly.
- `++`/`--` on `bool`, and `--` on `null`, warn.
- `php://memory`/`php://temp` allow seeking past the end (zero-filled).
- `mb_strtolower()`/`mb_convert_case()` apply Greek final sigma.

## Deprecated
- `++` on empty or non-alphanumeric strings, `--` on empty or non-numeric strings (`str_increment()`/`str_decrement()` exist).
- `get_class()`/`get_parent_class()` without arguments.
- `assert_options()`, `ASSERT_*` constants and `assert.*` INI settings (including in `phpunit.xml` `<ini>`) — use `zend.assertions`.
- `ReflectionProperty::setValue()` with one argument.
- `mb_strimwidth()` with negative width; `MT_RAND_PHP`; `ldap_connect()` with two arguments; `SQLite3::enableExceptions(false)`; `Phar::setStub()` with a resource; `ZipArchive::FL_RECOMPRESS`.

## Rector covers
Rector 2.7.0 set `php83`: `RemoveGetClassGetParentClassNoArgsRector`, `CombineHostPortLdapUriRector`, `DynamicClassConstFetchRector`, `JsonValidateRector`.
- **Skipped by default (risky):** `AddTypeToConstRector` (restricts overriding constants in subclasses), `ReadOnlyAnonymousClassRector`.
Not covered: `range()` changes, `++`/`--` on strings, `assert_options()` and `assert.*` INI.

## Tools miss — review manually
- `range()` calls with computed bounds or steps.
- `++` on string variables (counters read from input).
- `assert.*` lines in `phpunit.xml(.dist)` and `php.ini` snippets in CI.

## Grep patterns
Regexes are ripgrep syntax (usable with the Grep tool). Review every hit; a hit is a place to look, not proof of a bug.

- `\brange\(` — stricter bounds
- `\bnumber_format\(` — negative decimals
- `get_class\(\s*\)|get_parent_class\(\s*\)` — deprecated
- `assert_options|ASSERT_|assert\.` — deprecated
- `\+\+\$[a-zA-Z_]+|\$[a-zA-Z_]+\+\+` — string increment
- `\bstrtok\(` — start token
