# PHP 8.4 → 8.5

Read this file when the migration range includes PHP 8.5.

## Official sources
- https://www.php.net/manual/en/migration85.incompatible.php
- https://www.php.net/manual/en/migration85.deprecated.php
- https://www.php.net/manual/en/migration85.other-changes.php
- https://www.php.net/manual/en/migration85.new-functions.php
- https://github.com/php/php-src/blob/PHP-8.5/UPGRADING

## Breaking
- Casting a float (or numeric float string) that cannot be represented as an `int` warns, for explicit and implicit casts. Casting `NAN` to other types warns.
- Destructuring a non-array (other than `null`) with `[]`/`list()` warns.
- `printf()` family: a format without explicit precision no longer resets precision; it acts as precision 0. Review `%f`/`%e`.
- `setlocale()` with integer `0` as the locales argument throws `TypeError`.
- `class_alias()` cannot use `array` or `callable` as the alias.
- Loose comparison of enums or internal objects with booleans matches `(bool)$object`.
- `#[\Attribute]` on an abstract class, enum, interface or trait is a compile error.
- Traits are bound before the parent class.
- `disable_classes` INI removed; `ArrayObject` no longer accepts enums; `SplFileObject::fwrite()` `$length` defaults to `null`.
- Opcache is always built in; Intl needs ICU 57.1+; mbstring uses Unicode 17.0 tables.
- `SimpleXMLElement::xpath()` warns and returns `false` for non-node-set results; PDO fetch-mode checks are stricter.

## Deprecated
- **`chr()` with an integer outside 0–255** → `chr($n & 0xFF)` with an `int` (exactly the old behaviour; `% 256` differs for negative numbers).
- **`ord()` with a string that is not exactly one byte** → `ord($s[0])`.
- **Non-canonical casts** `(boolean)`, `(integer)`, `(double)`, `(binary)` → `(bool)`, `(int)`, `(float)`, `(string)`.
- **`null` as an array offset** (`$a[null]`, `$arrayAccess[] = …` passing `null` to `offsetSet()`, `array_key_exists(null, …)`) → use `''` explicitly or reject `null`.
- Backtick shell operator → `shell_exec()`.
- `case X;` with a semicolon → `case X:`.
- `__sleep()`/`__wakeup()` (soft) → `__serialize()`/`__unserialize()`.
- `__debugInfo()` returning `null` → return `[]`.
- `Reflection*::setAccessible()`; `ReflectionClass::getConstant()` for a missing constant; `ReflectionProperty::getDefaultValue()` without a default.
- Closure binding misuse (binding an instance to a static closure, unbinding `$this`).
- Output from inside a user output handler.
- `spl_autoload_unregister(spl_autoload_call)`.
- `SplObjectStorage::contains()`, `attach()`, `detach()` → `offsetExists()`, `offsetSet()`, `offsetUnset()`; `ArrayObject`/`ArrayIterator` with objects.
- `curl_close()`, `curl_share_close()`, `finfo_close()`, `imagedestroy()`, `xml_parser_free()` (no-ops), `finfo_buffer()` `$context`.
- `MHASH_*` constants, `DATE_RFC7231`, `mysqli_execute()`, `socket_set_timeout()`, `readdir()`/`rewinddir()`/`closedir()` with `null`, `$http_response_header`, PDO `uri:` DSN, driver-specific `PDO::` constants and methods (use `Pdo\Mysql`, `Pdo\Sqlite`, …), `intl.error_level`, `report_memleaks`, `register_argc_argv` on non-CLI SAPIs, `openssl_pkey_derive()` `$key_length`.

## Rector covers
Rector 2.7.0 set `php85` (18 rules):
- Fixes: `ChrArgModuloRector` (`chr($x)` → `chr($x % 256)`), `OrdSingleByteRector`, `RenameCastRector` (non-canonical casts), `ArrayKeyExistsNullToEmptyStringRector`, `ShellExecFunctionCallOverBackticksRector`, `ColonAfterSwitchCaseRector`, `NullDebugInfoReturnRector`, `RemoveFinfoBufferContextArgRector`, `RemoveFuncCallRector` (deprecated no-op calls such as `curl_close()`), `RemoveFuncCallArgRector`, `RenameFunctionRector`, `RenameConstantRector`, `RenameMethodRector`, `RenameClassConstFetchRector`.
- Modernisation: `ArrayFirstLastRector` (needs PHP 8.5 at runtime), `AddOverrideAttributeToOverriddenPropertiesRector`.
- **Skipped by default (risky):** `SleepToSerializeRector`, `WakeupToUnserializeRector` (change the serialized format of stored sessions/caches).
Not covered — **fix by hand**: `null` offsets reaching `ArrayAccess::offsetSet()` or `$a[null]`, float → int casts that overflow, `printf` precision, destructuring non-arrays. Note `ChrArgModuloRector` keeps a float operand when the input is a float — make it an `int` first.

## Tools miss — review manually
- Float math feeding `chr()`, `pack()`, array keys or `%` — confirm every value is an in-range `int` (e.g. WAV/byte generation: `chr((int) floor(...))`, `intdiv()`).
- `ArrayAccess::offsetSet()` implementations: `$obj[] = …` passes `null` — reject or handle it.
- `printf`/`sprintf` with `%f`/`%e` and no precision.
- Destructuring values that may be `false`.

## Grep patterns
Regexes are ripgrep syntax (usable with the Grep tool). Review every hit; a hit is a place to look, not proof of a bug.

- `\bchr\(` — argument is an in-range `int`
- `\bord\(` — argument is one byte
- `\((boolean|integer|double|binary)\)` — non-canonical cast
- `` `[^`]*` `` outside strings — backtick operator
- `\bcase\s+[^:]+;` — semicolon after case
- `function\s+__(sleep|wakeup)\b` — soft-deprecated
- `function\s+offsetSet\(` — `null` offset
- `setAccessible\(` — deprecated
- `\b(curl_close|finfo_close|imagedestroy|xml_parser_free)\(` — deprecated no-ops
- `[sv]?printf\([^)]*%[0-9]*[fFeE]` — precision change
