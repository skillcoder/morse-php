# PHP 7.3 → 7.4

Read this file when the migration range includes PHP 7.4.

## Official sources
- https://www.php.net/manual/en/migration74.incompatible.php
- https://www.php.net/manual/en/migration74.deprecated.php
- https://www.php.net/manual/en/migration74.removed-extensions.php
- https://www.php.net/manual/en/migration74.other-changes.php
- https://github.com/php/php-src/blob/PHP-7.4/UPGRADING

## Breaking
- Array access on `null`, `bool`, `int`, `float` or a resource raises a notice ("Trying to access array offset on value of type null").
- `fn` is a reserved keyword (not usable as a function or class name).
- `<?php` at the very end of a file (no trailing newline) is an open tag.
- `fread()` / `fwrite()` return `false` on failure (not `''`/`0`) and raise a notice.
- `PASSWORD_*` constants are strings.
- `get_object_vars()` on `ArrayObject` returns the object's own properties (also affects `array_walk()`, `reset()`, `current()` on it).
- `preg_*` with `PREG_UNMATCHED_AS_NULL` gives trailing unmatched groups as `null`.
- Serializing Reflection objects throws; `ReflectionProperty::IS_*` modifier values changed.
- `DateInterval` comparison with `==`/`<` warns and returns `false`.
- `get_declared_classes()` omits anonymous classes not yet instantiated.

## Removed extensions (moved to PECL)
Firebird/InterBase, Recode, WDDX. Drop matching `ext-*` from `composer.json`.

## Deprecated (removed in 8.0)
- Curly-brace offsets: `$s{0}` → `$s[0]`.
- Unparenthesised nested ternaries: `a ? b : c ? d : e`.
- `(real)` cast and `is_real()` → `(float)`, `is_float()`.
- `implode()` with reversed arguments → `implode($glue, $parts)`.
- `array_key_exists()` on objects → `property_exists()`/`isset()`.
- `money_format()`, `get_magic_quotes_gpc()`, `get_magic_quotes_runtime()`, `convert_cyr_string()`, `hebrevc()`, `ezmlm_hash()`, `restore_include_path()`.
- `base_convert()`, `bindec()`, `octdec()`, `hexdec()` notice on invalid characters.
- `mb_strrpos()` with the encoding as the 3rd argument.
- `parent` in a class without a parent; unbinding `$this` from a closure that uses it.
- `ReflectionType::__toString()`, static `Reflection*::export()`.
- `allow_url_include`, `FILTER_SANITIZE_MAGIC_QUOTES`, LDAP paged-result functions.

## Rector covers
Rector 2.7.0 set `php74`:
- Fixes: `CurlyToSquareBracketArrayStringRector`, `ParenthesizeNestedTernaryRector`, `RenameCastRector` (`(real)`), `RenameFunctionRector` (`is_real()`), `ArrayKeyExistsOnPropertyRector`, `FilterVarToAddSlashesRector`, `ExportToReflectionFunctionRector`, `MbStrrposEncodingArgumentPositionRector`, `MoneyFormatToNumberFormatRector`, `HebrevcToNl2brHebrevRector`, `RestoreIncludePathToIniRestoreRector`, `RestoreDefaultNullToNullableTypePropertyRector`.
- Modernisation: `ClosureToArrowFunctionRector`, `NullCoalescingOperatorRector`, `IfToNullCoalescingAssignRector`.
Not covered: `implode()` argument order (fixed by `ConsistentImplodeRector` in `php80`), `get_magic_quotes_*()`, array access on `null`, `fread()`/`fwrite()` results.

## Tools miss — review manually
- Array reads on values that can be `null`/`false` at runtime (`unpack()`, `json_decode()`, DB rows, optional config).
- `fread()`/`fwrite()` results compared with `0` or `''`.
- Binary/base-conversion helpers fed invalid characters.

## Grep patterns
Regexes are ripgrep syntax (usable with the Grep tool). Review every hit; a hit is a place to look, not proof of a bug.

- `\$[a-zA-Z_]+\{` — curly offset
- `\?[^:;]+:[^;]+\?[^:;]+:` — nested ternary
- `\(real\)|\bis_real\(` — removed
- `implode\(\s*\$` — argument order
- `array_key_exists\([^,]+,\s*\$this` — object argument
- `\b(money_format|get_magic_quotes_(gpc|runtime)|hebrevc|convert_cyr_string)\(` — removed
- `\b(fread|fwrite)\(` — `false` on failure
- `function\s+fn\s*\(|class\s+fn\b` — reserved word
