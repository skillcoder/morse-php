# PHP 8.0 → 8.1

Read this file when the migration range includes PHP 8.1.

## Official sources
- https://www.php.net/manual/en/migration81.incompatible.php
- https://www.php.net/manual/en/migration81.deprecated.php
- https://www.php.net/manual/en/migration81.other-changes.php
- https://github.com/php/php-src/blob/PHP-8.1/UPGRADING

## Breaking
- `htmlspecialchars()`, `htmlentities()`, `htmlspecialchars_decode()`, `html_entity_decode()`, `get_html_translation_table()` default to `ENT_QUOTES | ENT_SUBSTITUTE | ENT_HTML401` (single quotes become `&#039;`).
- Static variables in inherited (non-overridden) methods are shared with the parent method.
- Writing to `$GLOBALS` as a whole is not allowed (element writes still work).
- `readonly` is a keyword; `never` is reserved as a class name.
- `version_compare()` rejects undocumented operator abbreviations.
- Resources became objects: `finfo`, FTP, IMAP, LDAP, PgSQL, PSpell.
- MySQLi default error mode is exceptions; PDO MySQL/SQLite return native `int`/`float`.
- `Reflection*::setAccessible()` has no effect.

## Deprecated
- **Passing `null` to non-nullable internal function parameters** (`strlen(null)`, `trim(null)`, `str_replace(…, null)`, `explode(…, null)`, `mb_strtoupper(null)`).
- **Implicit float → int conversion that loses precision**: fractional floats as array keys, in `int` parameters, and with `%`, `<<`, `>>`, `|`, `&`, `^`, `~`.
- **Internal method return types**: overriding methods of internal interfaces/classes (`ArrayAccess`, `Iterator`, `IteratorAggregate`, `Countable`, `JsonSerializable`, …) without a compatible return type. Add the return type, or `#[\ReturnTypeWillChange]` if older PHP must still be supported.
- Autovivification from `false` (`$a = false; $a[] = 1;`).
- `Serializable` without `__serialize()`/`__unserialize()`.
- `ctype_*()` with non-string arguments.
- `key()`, `current()`, `next()`, `prev()`, `reset()`, `end()` on objects.
- Calling static members directly on a trait.
- `__sleep()` returning a non-array.
- `FILE_BINARY`, `FILE_TEXT`, `auto_detect_line_endings`, `strftime()`, `gmstrftime()`, `FILTER_SANITIZE_STRING`, `FILTER_SANITIZE_STRIPPED`, `mb_check_encoding()` without arguments, `date_sunrise()`, `date_sunset()`, `strptime()`, `mhash*()`, `odbc_result_all()`.

## Rector covers
Rector 2.7.0 set `php81`:
- Fixes: `RemoveReflectionSetAccessibleCallsRector`, `NullToStrictIntPregSlitFuncCallLimitArgRector`.
- Modernisation: `ArrayToFirstClassCallableRector`, `ClosureDelegatingCallToFirstClassCallableRector`, `ArrowFunctionDelegatingCallToFirstClassCallableRector`, `ClosureFromCallableToFirstClassCallableRector`, `FunctionFirstClassCallableRector`, `ReturnNeverTypeRector`, MyCLabs/Spatie enum conversions.
- **Skipped by default (risky):** `ReadOnlyPropertyRector` (breaks later writes, hydrators, `clone`/`unserialize` patterns).
Not covered — **fix by hand**: `null` passed to internal functions, implicit float → int, missing return types on internal-interface methods (`ArrayAccess`, `Iterator`, `Countable`, …), `Serializable`.

## Tools miss — review manually
- `null` reaching internal functions at runtime (untyped parameters, optional array entries). Tests with `failOnDeprecation` or PHPStan level ≥ 5 find these.
- Float arithmetic that ends in an `int` context: sample/byte math, `%`, `str_repeat()` counts, `chr()`, `range()`, `array_fill()`, array keys.
- Tests asserting escaped HTML output.

## Grep patterns
Regexes are ripgrep syntax (usable with the Grep tool). Review every hit; a hit is a place to look, not proof of a bug.

- `implements\s+[^{]*(ArrayAccess|Iterator|IteratorAggregate|Countable|JsonSerializable)` — return types on the methods
- `function\s+(offset(Get|Set|Exists|Unset)|current|key|next|rewind|valid|count|getIterator|jsonSerialize)\s*\([^)]*\)\s*\{` — missing return type
- `implements\s+[^{]*Serializable` — needs `__serialize()`
- `\s%\s*\d|%\s*\$` — float operands
- `floor\(|ceil\(|round\(` feeding `%`, `chr()`, keys — float to int
- `\bstrftime\(|FILTER_SANITIZE_STRING` — deprecated
- `\bhtml(specialchars|entities)\(` — new default flags
