# PHP 7.2 → 7.3

Read this file when the migration range includes PHP 7.3.

## Official sources
- https://www.php.net/manual/en/migration73.incompatible.php

- https://github.com/php/php-src/blob/PHP-7.3/UPGRADING

## Breaking
- `continue` that targets a `switch` warns ("Did you mean to use "continue 2"?"). It behaves like `break`.
- Heredoc/nowdoc closing markers may be indented; a body line that starts with the marker text (even indented) now ends the string → parse error.
- `compact()` with an undefined variable raises a notice.
- `ArrayAccess`: `$obj["123"]` calls `offsetGet("123")` with a string.
- Static properties are no longer separated by reference assignment; references from array/property reads are unwrapped immediately.
- Unpacking a `Traversable` with non-integer keys into arguments fails.
- An autoloader that throws stops the remaining autoloaders.
- `TypeError` and Reflection messages say `int`/`bool`, not `integer`/`boolean`.
- PCRE2: stricter character-class ranges (`[\w-.]` is an error), `preg_quote()` escapes `#`.
- BCMath `bcmul()`/`bcpow()` return the requested scale.

## Deprecated
- Case-insensitive constants: `define($name, $value, true)` and using such constants with another case.
- Non-string needles in `strpos`, `strrpos`, `stripos`, `strripos`, `strstr`, `strchr`, `strrchr`, `stristr` (cast to string or use `chr()`).
- Declaring a namespaced function called `assert()`.
- `fgetss()`, `SplFileObject::fgetss()`, `gzgetss()`, the `string.strip_tags` filter.
- `image2wbmp()`, explicit `FILTER_FLAG_SCHEME_REQUIRED`/`FILTER_FLAG_HOST_REQUIRED`, the `mbereg*` aliases, `pdo_odbc.db2_instance_name`.

## New, useful for fixes
`array_key_first()`, `array_key_last()`, `is_countable()`, `hrtime()`, `JSON_THROW_ON_ERROR`.

## Rector covers
Rector 2.7.0 set `php73`: `SensitiveDefineRector`, `SensitiveConstantNameRector`, `SensitiveHereNowDocRector`, `StringifyStrNeedlesRector`, `RegexDashEscapeRector`, `IsCountableRector`, `ArrayKeyFirstLastRector`, `ArrayKeysToArrayKeyFirstLastRector`, `SetCookieRector`, `RenameFunctionRector`.
Not covered: `continue` targeting `switch` (no rule in the set), `compact()` with undefined variables, `fgetss()`.

## Tools miss — review manually
- Heredoc/nowdoc bodies that contain the closing marker text.
- Regexes with ranges inside character classes (`-` not at the start or end).
- Tests that match `integer`/`boolean` in messages.
- Autoloaders that throw.

## Grep patterns
Regexes are ripgrep syntax (usable with the Grep tool). Review every hit; a hit is a place to look, not proof of a bug.

- `\bcontinue\s*;` inside `switch` — should be `continue 2` or `break`
- `define\([^)]*,\s*true\s*\)` — case-insensitive constant
- `\b(strpos|stripos|strrpos|strripos|strstr|stristr|strchr|strrchr)\(` — needle may be an int
- `<<<['"]?[A-Z_]+` — heredoc/nowdoc bodies
- `\[[^\]]*\\w-` — PCRE2 class ranges
- `\bfgetss\(|gzgetss\(` — deprecated
- `\bcompact\(` — undefined variables
