## Breaking
- New global functions can clash with user functions of the same name: `array_find()`, `array_find_key()`, `array_any()`, `array_all()`, `mb_trim()`, `mb_ltrim()`, `mb_rtrim()`, `mb_ucfirst()`, `mb_lcfirst()`, `fpow()`, `request_parse_body()`, `bcceil()`, `bcfloor()`, `bcround()`, `bcdivmod()`. Guard polyfills with `function_exists()`.
- `round()`: an invalid mode throws `ValueError`; pre-rounding was removed, so some edge cases change (`round(0.49999999999999994)` is `0.0`).
- `strcspn()` with empty `$characters` returns the string length.
- `str_getcsv()` separator/enclosure must be one byte; escape one byte or empty.
- `unserialize()` `allowed_classes` must be an array of class names or a bool.
- `exit()`/`die()` behave like functions and obey `strict_types`.
- `mb_substr()`/`mb_strstr()` index invalid strings consistently.
- `GMP` is final; `SplFixedArray` out-of-bounds throws `OutOfBoundsException`.
- PCRE2 10.44: `{,3}` is a quantifier, not literal text.
- `password_hash()` default bcrypt cost is 12.
- Closure names include the defining function and line.
- IMAP, OCI8, PDO_OCI and Pspell are no longer bundled (moved to PECL) — check `ext-*` requirements.

## Deprecated
- **Implicitly nullable parameters**: `T $x = null` → `?T $x = null`.
- `trigger_error()` with `E_USER_ERROR` (throw an exception or `exit()` instead).
- The `E_STRICT` constant.
- A class named `_`.
- `0 ** -n` / `pow(0, -n)` → `fpow()`.
- Relying on the default `escape` of `fputcsv()`, `fgetcsv()`, `str_getcsv()`, `SplFileObject::setCsvControl()` — pass it explicitly.
- `lcg_value()` → `Random\Randomizer::getFloat()`.
- `unserialize()` uppercase `S` tag; `stream_context_set_option()` with two arguments; session `SID` and related settings; `xml_set_object()`; `DatePeriod` ISO string constructor; `ReflectionMethod::__construct()` with one argument.

## Rector covers
Rector 2.7.0 set `php84`: `ExplicitNullableParamTypeRector` (implicit nullable → `?T`), `AddEscapeArgumentRector` (CSV `escape`), `RoundingModeEnumRector`, `NewMethodCallWithoutParenthesesRector`, `ForeachToArrayAllRector`, `ForeachToArrayAnyRector`, `ForeachToArrayFindRector`, `ForeachToArrayFindKeyRector`.
Not covered: `E_USER_ERROR`, `E_STRICT`, user functions clashing with new 8.4 names, `lcg_value()`.

## Tools miss — review manually
- User-defined functions or polyfills named like the new 8.4 functions.
- `round()` edge cases in money/sample math.
- CSV code relying on the default escape character.

## Grep patterns
Regexes are ripgrep syntax (usable with the Grep tool). Review every hit; a hit is a place to look, not proof of a bug.

- `\(\s*[?]?[A-Za-z_\\]+\s+\$[a-zA-Z_]+\s*=\s*null` without `?` — implicit nullable
- `,\s*[A-Za-z_\\]+\s+\$[a-zA-Z_]+\s*=\s*null` without `?` — implicit nullable
- `E_USER_ERROR|\bE_STRICT\b` — deprecated
- `function\s+(array_find|array_find_key|array_any|array_all|mb_trim|mb_ltrim|mb_rtrim|mb_ucfirst|mb_lcfirst|fpow)\b` — name clash
- `\b(fputcsv|fgetcsv|str_getcsv)\(` — explicit `escape`
- `\blcg_value\(` — deprecated
- `\bround\(` — edge cases
