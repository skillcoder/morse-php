Read this file when the migration range includes PHP 7.1.

## Breaking
- Too few arguments to a **user** function throws `ArgumentCountError` (was a warning).
- Dynamic calls to scope-introspection functions are forbidden: `extract`, `compact`, `func_get_args`, `func_get_arg`, `func_num_args`, `get_defined_vars`, `parse_str` with one argument, `mb_parse_str`, `assert` with a string (e.g. `$f = 'extract'; $f()` or `array_map('compact', …)`).
- `void` and `iterable` cannot be class/interface/trait names.
- `$this` cannot be reassigned, unset, used as a parameter, or made global.
- `return;` with no value in a function with a non-void return type is a compile error.
- `$str[] = $x` on a string is a fatal error. `$a = ''; $a[10] = 'x';` now gives a space-padded string, not an array.
- `rand()`/`srand()` are aliases of `mt_rand()`/`mt_srand()`; `mt_rand()` uses the fixed Mersenne Twister. Seeded sequences change (`rand`, `shuffle`, `str_shuffle`, `array_rand`).
- Arithmetic on non-numeric strings warns "A non-numeric value encountered"; leading-numeric strings (`"1b"`) give a notice.
- Numeric-string conversion respects scientific notation (`"1e3"` → 1000) in `(int)`, `intval()`, `settype()`, `decbin()`, `decoct()`, `dechex()`.
- Octal escapes above `\377` warn.
- Closure `use` variables may not share a name with a parameter, a superglobal or `$this`.
- Destructors are not called for objects whose constructor threw.
- `call_user_func()` always warns when the target takes a reference.
- Sorting: the order of equal elements may change.
- Array keys created by reference assignment are ordered differently.
- `DateTime` created from "now" includes microseconds (`new DateTime() == new DateTime()` is usually false).
- `json_encode()` uses `serialize_precision` (default now -1) for floats.
- Messages: "Catchable fatal error" became "Recoverable fatal error"; `TypeError` messages mention `or null`.
- Session INI `session.entropy_file`, `session.entropy_length`, `session.hash_function`, `session.hash_bits_per_character` removed.

## Deprecated
- `ext/mcrypt` (moved to PECL in 7.2).
- `mb_ereg_replace()` / `mb_eregi_replace()` `e` modifier.

## Rector covers
Rector 2.7.0 set `php71`:
- Fixes: `AssignArrayToStringRector` (`$s = ''; $s[] = …` → array), `BinaryOpBetweenNumberAndStringRector`.
- Modernisation: `MultiExceptionCatchRector`, `ListToArrayDestructRector`, `IsIterableRector`.
- **Skipped by default (risky):** `RemoveExtraParametersRector` (deletes call arguments beyond the declared parameters, including ones read via `func_get_args()` in callee code Rector cannot see).

## Tools miss — review manually
- Calls to user functions with too few arguments (only visible at runtime or with PHPStan).
- Tests that assert seeded `rand()`/`shuffle()` output.
- Arithmetic on values that may be non-numeric strings (user input, `unpack()` results, CSV fields).
- Tests matching exact error messages.

## Grep patterns
Regexes are ripgrep syntax (usable with the Grep tool). Review every hit; a hit is a place to look, not proof of a bug.

- `\$[a-zA-Z_]+\[\]\s*=` — string append via `[]` (confirm the variable is an array)
- `\b(mt_)?s?rand\(|shuffle\(|array_rand\(` — seeded randomness
- `['"](extract|compact|func_get_args|get_defined_vars|parse_str)['"]` — dynamic introspection calls
- `\bmcrypt_` — deprecated extension
- `class\s+(Void|Iterable)\b` — reserved names
- `Catchable fatal error` — changed message
