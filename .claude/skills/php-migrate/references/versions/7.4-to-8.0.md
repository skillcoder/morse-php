## Breaking: comparisons and numbers
- String ↔ number comparison: when a number meets a non-numeric string, the number is cast to string. `0 == "foo"`, `0 == ""`, `42 == "42foo"` are now **false**; `'' < 0` is true. Affects `==`, `!=`, `<`, `>`, `<=>`, `switch`, `in_array()`/`array_search()` without strict, `sort()` with mixed values.
- Numeric strings may have trailing whitespace (`"42 "` is numeric).
- Arithmetic on a non-numeric string throws `TypeError`; leading-numeric (`"123abc"`) warns.
- Arithmetic/bitwise/`++`/`--` on arrays, resources, objects throws `TypeError` (array `+` array still works).
- Division by zero with `/` throws `DivisionByZeroError` (use `fdiv()` for IEEE results); `%` already threw.
- Float to string is locale-independent; default locale is `"C"`.
- `abs()`, `ceil()`, `floor()`, `round()` respect `strict_types`.

## Breaking: syntax
- `match` and `mixed` are reserved; `#[` starts an attribute (a `#[` comment breaks).
- `.` and `+`/`-` precedence: `"a" . $x + $y` is `"a" . ($x + $y)`.
- Unparenthesised nested ternaries are a compile error.
- `$str{0}` removed; `(real)` and `(unset)` casts removed.
- A method named after its class is no longer a constructor.
- Calling a non-static method statically throws `Error`.
- Magic method signatures are checked; incompatible inherited signatures are always fatal.
- Optional parameter before a required one: the default is ignored (the parameter is effectively required).

## Breaking: strings
- `strpos()` family: non-string needles are no longer read as ASCII codes; empty needles are allowed (`strpos($h, '')` is 0).
- `substr()`, `mb_substr()`, `iconv_substr()`, `grapheme_substr()` return `""` for out-of-range offsets (not `false`).
- `explode()` with an empty separator throws `ValueError`.
- `implode()` with reversed arguments removed; `vsprintf()`/`vprintf()`/`vfprintf()` require an array.
- String offset reads out of range, and `null`/bool/float offsets, warn; multi-byte assignment to an offset warns.

## Breaking: arrays
- `count()` on a non-countable throws `TypeError`.
- `array_key_exists()` on objects throws `TypeError`.
- Undefined variable, array key and property reads are **warnings**; array-to-string conversion is a warning.
- Sorting is stable. Sort callbacks returning `bool` (`$a > $b`) are deprecated — return `$a <=> $b`.
- If the first numeric key is negative `n`, the next implicit key is `n+1`.
- `call_user_func_array()` treats string keys as named arguments.

## Breaking: errors and functions
- Internal functions throw `TypeError`/`ValueError`/`ArgumentCountError` instead of warning and returning `null`/`false` (e.g. passing `false` from a failed `preg_split()` into `array_map()`).
- `@` no longer silences fatal errors; default `error_reporting` is `E_ALL`.
- Undefined constants throw `Error`.
- `assert()` throws by default; string assertions are not evaluated.
- Error handlers no longer receive `$errcontext`.
- `parse_str()` requires the result argument; `mktime()`/`gmmktime()` require an argument.
- `parse_url()` distinguishes missing (`null`) from empty (`""`) query/fragment.
- `password_hash()` ignores `salt`; `crypt()` requires a salt.
- Resources became objects for curl, GD, OpenSSL, sockets, XML, Zip and others — `is_resource()` checks become `!== false`.

## Removed
`create_function()`, `each()`, `__autoload()`, `money_format()`, `hebrevc()`, `convert_cyr_string()`, `ezmlm_hash()`, `restore_include_path()`, `get_magic_quotes_gpc()`, `get_magic_quotes_runtime()`, `fgetss()`, `gzgetss()`, `image2wbmp()`, `define()` third argument `true`.

## Deprecated
- Required parameter after an optional one (`function f($a = [], $b)`); `Type $x = null` before a required one is still allowed.
- Sort callbacks returning `bool`.
- `ReflectionParameter::getClass()`, `isArray()`, `isCallable()`; `ReflectionFunction::isDisabled()`.
- `libxml_disable_entity_loader()`, procedural `zip_*`, some `pg_*` aliases, Enchant functions.

## Rector covers
Rector 2.7.0 set `php80`:
- Fixes: `ConsistentImplodeRector`, `RemoveParentCallWithoutParentRector`, `FinalPrivateToPrivateVisibilityRector`, `AddParamBasedOnParentClassMethodRector`, `SetStateToStaticRector`, `RenameFunctionRector`, `FunctionArgumentDefaultValueReplacerRector`, `ArgumentAdderRector`.
- Modernisation: `StrContainsRector`, `StrStartsWithRector`, `StrEndsWithRector`, `ClassOnObjectRector`, `ClassOnThisVariableObjectRector`, `GetDebugTypeRector`, `StringableForToStringRector`, `RemoveUnusedVariableInCatchRector`, `TernaryToNullsafeCoalesceRector`, `StaticCallToFuncCallRector`.
- **Skipped by default (risky):** `ChangeSwitchToMatchRector` (`match` is strict and throws `UnhandledMatchError`), `ClassPropertyAssignToConstructorPromotionRector` (public API/signature change), `OptionalParametersAfterRequiredRector` (adds defaults, changes signatures).
Not covered: string↔number comparisons, division by zero, empty `explode()` separators, `count()` on non-countables, `false` passed on to internal functions.

## Tools miss — review manually
- Every loose comparison that can mix numbers and strings (`==`, `switch`, `in_array()` without `true`). Static tools cannot know the runtime types.
- `assertEquals()` in tests (loose comparison) whose meaning changes.
- Values that can be `0` passed to `/` (setters, config).
- `explode()` separators that can be empty.
- Functions whose `false` return is passed on unchecked (`preg_split()`, `file_get_contents()`, `json_encode()`).
- `=== false` checks on `substr()`.

## Grep patterns
Regexes are ripgrep syntax (usable with the Grep tool). Review every hit; a hit is a place to look, not proof of a bug.

- `[^=!]==[^=]|!=[^=]` — loose comparisons with strings/numbers
- `\bswitch\s*\(` — loose comparison
- `in_array\([^)]*\)` without `, true` — loose comparison
- `/\s*\$` — division by a variable that may be 0
- `explode\(\s*\$` — separator may be empty
- `\b(create_function|each|money_format|get_magic_quotes_gpc)\(` — removed
- `\$[a-zA-Z_]+\{` — curly offset (removed)
- `usort|uasort|uksort` + `return \$a\s*>` — bool comparator
- `#\[` in comments — now an attribute
- `\bmatch\b|\bmixed\b` as identifiers — reserved
